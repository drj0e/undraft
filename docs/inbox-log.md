# Inbox Log

One line per Undraft inbox note the writer routine has consumed, so a note is used once and the reviewer can find the note behind an `origin: inbox` post. The repo is public: record the Drive file ID and the outcome only. Never the note's title, text, or a quote from it (see CLAUDE.md "Inbox notes").

Format:
- `- YYYY-MM-DD <drive-file-id> -> <post-slug>` when a post was written from it
- `- YYYY-MM-DD <drive-file-id> -> skipped: <generic reason>` when it couldn't become a post
